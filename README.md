# Forward

Forward 播放器组件：聚合实时榜单 + 瓜子影视播放源。

[![Stars](https://img.shields.io/github/stars/ZenmoFeiShi/Forward?style=flat-square)](https://github.com/ZenmoFeiShi/Forward/stargazers)

## 文件

| 文件 | 说明 |
|---|---|
| `forward_rank.js` | ForwardWidget 模块（榜单聚合 / 播放源） |

## 功能

- Netflix / Disney+ / Apple TV+ / HBO Max / Prime Video 新片榜
- 本周国剧 / 美剧 / 韩剧 / 英剧 / 日剧 / 泰剧 / 动漫 / 电影 / 综艺 / 纪录片排行
- 瓜子影视搜索与播放源

## 使用方式

在 Forward 播放器中添加远程组件：

```text
https://raw.githubusercontent.com/ZenmoFeiShi/Forward/main/forward_rank.js
```
